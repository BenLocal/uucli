# 交流与语言约定

> 和用户交流用简体中文；写进仓库的内容（代码注释、文档、提交信息）一律英文。

- 交流语言：和用户对话默认使用简体中文；用户明确要求时改用英文。
- 仓库内容：代码注释、`docs/spec.md`、`README.md`、错误信息和 `--help` 文本、提交信息、PR 描述都用英文，和仓库既有风格一致（远端是 GitHub，现有内容全是英文）。
- 例外：本目录 `docs/agents-dot-md/` 和 `docs/memory/` 是写给 agent 的说明，用简体中文。
- 标识符、协议字段名、官方报错原文（如 `device_not_logged_in`）保持原样，不翻译。
